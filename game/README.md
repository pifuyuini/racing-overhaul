# 萌爪海湾 · Pawprint Paradise

一款默认自动驾驶的原创海岛卡丁车游戏：四位动物车手、一条海岛赛道、三圈竞速。车辆默认自动加速和过弯，玩家把精力放在选线、氮气、碰撞攻防、七种道具和赛道互动上；手动模式提供带惯性、抓地变化与制动的驾驶。TypeScript + Three.js，游戏逻辑、画面、音频与个人纪录全部在浏览器内运行。

## 开始游玩

公开入口：[开始游玩](https://pifuyuini.github.io/racing-overhaul/)。部署状态见[仓库入口说明](../README.md)。

使用启用硬件加速、支持 WebGL 2 的桌面浏览器。首次点击菜单后才会启用声音。

### 轻松驾驶（默认）

不用一直按油门，也不用精确控制方向。完全不操作也能跑完三圈；主动选择补给路线、冲刺和把握互动时机会更快。画面底部与提示卡上的按钮均可点击。

| 按键                                | 操作                           |
| ----------------------------------- | ------------------------------ |
| A / 左方向键                        | 选择左线，自动保持             |
| W / 上方向键（S / 下方向键 也可以） | 回到中线                       |
| D / 右方向键                        | 选择右线，自动保持             |
| 空格                                | 氮气冲刺，按一次消耗 30 点     |
| E                                   | 使用道具                       |
| F                                   | 在提示窗口完成飞跃、漂移或回旋 |
| R                                   | 返回最近有效检查点             |
| Esc                                 | 暂停 / 继续                    |

- 氮气初始 60 点、上限 100 点，持续恢复；拾取青色晶体额外补充 20 点。冲刺持续约 1.8 秒，结束后再按一次可继续点火。
- 每圈两处选线门：左线补充 35 点氮气，右线给道具（已有道具时补充 20 点氮气），中线安全通过并补充 10 点氮气。计时模式右线提供短时加速。
- 每圈三次互动：木桥飞跃带来真实腾空与落地，可越过地面陷阱；砂岩漂移改变抓地与侧滑，成功后获得出弯奖励；海风区有横向风力，按 F 把握窗口可获得顺风稳定与推力。金色时机奖励更多；错过仍可继续。
- 受击和碰撞会影响速度与侧向动量，车辆会自行恢复。受击期间氮气与互动禁用，泡泡护盾仍可使用；其他道具等恢复后再用，按钮会说明原因。腾空时保留香蕉、墨迹和近身潮汐道具，落地后可用。

### 手动驾驶（选角页切换）

亲自掌握油门、转向、制动与漂移。辅助、手动和 AI 使用同一套纵向动力；起步渐进、高速恢复更慢、滑行保留惯性，砂地和湿地需要更柔和地控制。手动与轻松驾驶的个人纪录分开，旧成绩继续兼容。

| 按键                      | 操作                                 |
| ------------------------- | ------------------------------------ |
| W / 上方向键              | 加速                                 |
| S / 下方向键              | 刹车；低速时倒车                     |
| A、D / 左方向键、右方向键 | 左右转向                             |
| 空格 + 转向               | 漂移蓄力                             |
| 松开空格                  | 释放漂移加速；蓝色为一级，金色为二级 |
| E                         | 使用当前道具                         |
| F                         | 在赛道提示窗口触发真实互动           |
| R                         | 回到最近通过的检查点                 |
| Esc                       | 暂停 / 继续                          |

离开窗口或切换标签页会自动暂停。恢复比赛前清空旧按键，避免车辆突然转向或误用道具。

方向键、WASD 与屏幕选线按钮的左右含义保持一致。游戏里的箭头均由 SVG、Canvas 路径或三维几何绘制，不使用箭头文字字符。互动提示位于侧边，区分提前准备、现在可按、最佳窗口与错过；氮气和道具按钮会显示当前不可用的原因。

## 游戏内容

- **团团 / 小熊猫**：均衡偏稳；**薯条 / 水豚**：较重、抗撞且极速略高；**柚子 / 狐狸**：轻巧灵活，侧撞更需稳车；**冰棒 / 企鹅**：起步更快。角色姿态、轮胎、悬架、耳尾和握轮动作随真实驾驶状态变化。
- **道具竞速**：玩家和 7 名 AI 比赛，轻松 / 标准 / 挑战三档难度，3 圈决胜。轻松档适合熟悉路线；标准与挑战档的对手会更积极地通过弯道，需要选线、氮气和互动来争取名次。
- **计时挑战**：独享赛道，没有对手和道具；计时纪录与道具赛分开。
- **晴浪海湾**：海滩、棕榈树林、木桥、砂岩弯道、湿滑潮汐路段和海风区。沥青、木板、砂地、湿地各有抓地与阻力；青色地面图形为加速带。
- **七种道具**：加速果汁、泡泡护盾、前向水球、香蕉皮，以及追踪海螺、潮汐冲击和墨汁陷阱。详细用途见下表。
- **赛车碰撞**：追尾传递速度，侧撞产生真实推移，质量影响对抗；辅助车被推开后渐进回线。护栏有接触与摩擦，已完赛对手退出竞技碰撞和道具目标。
- 玩家完赛立即结算；尚未完赛的对手按有效赛道进度排列，并明确标记。
- 个人纪录按驾驶方式、角色和比赛模式保存。设置和纪录仅存在当前浏览器，不上传服务器。
- 音量、音乐开关与三档画质可在设置中调整；流畅档关闭动态阴影并降低渲染分辨率。

### 道具与攻防

| 道具     | 实际作用与应对                                                         |
| -------- | ---------------------------------------------------------------------- |
| 加速果汁 | 短时额外推力，适合出弯和追击。                                         |
| 泡泡护盾 | 持续 6 秒，挡一次攻击；受击时仍可开启。                                |
| 前向水球 | 沿前方直射，需要对准车道；对手可换线躲避。                             |
| 香蕉皮   | 后置地面陷阱，命中会短时失控；换线或腾空可以避开。                     |
| 追踪海螺 | 锁定前方 70 米内目标，转弯能力有限；无目标时保留，可用护盾或换线应对。 |
| 潮汐冲击 | 近身扩散至 8.5 米，推离附近对手，每个目标只受一次作用。                |
| 墨汁陷阱 | 在身后留下低抓地区域，使对手打滑而非眩晕；可绕行或跳过。               |

驾驶状态条会优先提示来袭、受击、侧滑、碰撞、腾空和落地；音效、轮痕、粒子与车身姿态读取相同物理状态。

## 开发与构建

使用 Node.js 24 与 npm。所有游戏命令在仓库的 `game/` 内执行：

```sh
cd game
npm ci
npm run dev
```

打开开发服务器输出的地址，默认是 **http://localhost:5173/**。

```sh
npm test
npm run build
npm run preview
```

`npm run build` 先进行 TypeScript 检查，再生成 `dist/`。预览默认位于 **http://localhost:4173/**。产物可由普通静态 HTTP 服务承载；资源已打包，运行时不依赖 CDN、在线字体或外部素材服务。Vite 的单包大小提示来自随包交付的三维引擎。

依赖固定版本，`package-lock.json` 随源码提交：运行依赖为 Three.js；开发与验证使用 TypeScript、Vite、Three.js 类型、Vitest、Playwright Core 与 Prettier。Playwright 使用已有的 Chrome，可用 `CHROME_PATH` 指定其可执行文件，不下载浏览器。

GitHub Pages 构建与自动发布见[仓库入口](../README.md#github-pages-发布)。本游戏目录保留现有结构，不需要移动源码。

## 源码结构

- `src/simulation.ts`：统一动力、质量与二维碰撞、横向惯性、真实跳跃落地、七道具、AI 与比赛规则。
- `src/track.ts`：赛道曲线、等距采样、道路投影和高度，以及世界与模拟共享的路面、风区和护栏边界。
- `src/models.ts`、`src/world.ts`：四种独立轮廓的动物、握方向盘的坐姿、车辆、海岛、平滑镜头、特效、近景角色图及资源释放。
- `src/icons.ts`：统一绘制的界面、方向键和道具 SVG 图标。
- `src/ui.ts`、`src/style.css`：菜单、选角、HUD、暂停、设置和成绩。
- `src/input.ts`、`src/audio.ts`、`src/storage.ts`：键盘输入、合成音效与音乐、设备内存档。
- `src/types.ts`：模块共享类型。
- `test/`：规则、输入、12 种角色 / 难度的零操作完赛、奖励、纪录兼容及完整 AI 比赛测试。
- `scripts/assisted-qa.mjs`：新玩法完整流程、真实时间零操作 / 主动操作对照、提示边界与存档检查。
- `scripts/production-qa.mjs`：构建版自动加速、选线、氮气、暂停、资源离线性和禁止存储访问检查。
- `test/overhaul.test.ts`：冲量与动量、统一动力、七道具、真实高度、护栏、风区和生命周期回归。
- `scripts/overhaul-qa.mjs`：真实 E / F 与碰撞攻防、七道具实体 / 命中 / 躲避、跳跃落地、抓地、暂停与资源循环。
- `scripts/controls-qa.mjs`：真实相机投影下的左右 / 漂移、左右补给门、提示状态、焦点误触、文字箭头清理、角色与布局回归。
- `scripts/repair-qa.mjs`：选项切换后的键盘焦点、320 / 575 / 700 像素窗口中的成绩信息与横向溢出，以及异常成绩存档的结算、保存和刷新恢复。
- `scripts/browser-qa.mjs`：菜单、真实键盘漂移、道具、暂停、重开、成绩、纪录和布局检查。
- `scripts/keyboard-race-qa.mjs`：真实时间、实际键盘控制的三档难度完整比赛及帧时记录。

模拟使用 60Hz 固定步长，绘制插值包含离地高度。轻松驾驶用带阻尼的路线引导叠加真实横向惯性，手动模式自由转向；三类车手共用有限动力，碰撞按世界速度与质量处理。两种模式共享检查点、道具、路面、跳跃、排名和比赛流程。开发版的 `__PAWPRINT_TEST__` 测试入口会在生产构建时移除。

## 验证脚本

运行浏览器检查前，从仓库根目录创建专属临时目录及 `.codex-tmp` 标记；截图、日志与浏览器临时文件留在该目录。先在另一个终端运行开发服务器，再执行：

```sh
qa_dir="$(pwd)/tmp/$(date +%Y%m%d-%H%M%S)-local-qa"
mkdir -p "$qa_dir"
touch "$qa_dir/.codex-tmp"
cd game
QA_ARTIFACT_DIR="$qa_dir" \
TMPDIR="$qa_dir" \
QA_BASE_URL=http://localhost:5173/ \
npm run qa
```

需要指定系统浏览器时，同样加入 `CHROME_PATH` 环境变量。`QA_ARTIFACT_DIR` 与 `TMPDIR` 应指向同一个专属目录。

同样设置环境变量后，`npm run qa:assisted` 运行约 5 分钟的新玩法浏览器检查，`node scripts/keyboard-race-qa.mjs` 运行手动版长时间键盘测试。两者使用开发版测试入口；`npm run qa:production` 测试 4173 构建版。可用 `QA_BASE_URL` 指定新玩法 / 构建版的实际地址（例如端口回退到 4174 时）。

同样设置 `QA_ARTIFACT_DIR` 和 `TMPDIR` 后，`npm run qa:repair` 可快速检查本轮界面修复。两变量须指向同一个带 `.codex-tmp` 标记的本任务目录，避免截图与浏览器临时文件写入其他位置。

同样设置临时目录后，`npm run qa:controls` 检查方向、反馈与角色显示。手动长跑默认验证三档难度，也可用 `QA_DIFFICULTIES=normal node scripts/keyboard-race-qa.mjs` 单独验证标准难度；方向控制器使用与真实键盘一致的左右约定。

同样设置临时目录后，`npm run qa:overhaul` 默认验证 collision、items、interactions、ui、lifecycle 全组。诊断可用 `QA_OVERHAUL_GROUPS` 选择子组，报告会注明范围；完整验收使用默认全组。

源码格式可用 `npm run format:check` 检查；`npm run format` 仅整理本游戏内的文件。

历史结果见 [VALIDATION.md](VALIDATION.md)，可公开的原始数据及发布验收状态见 [docs/validation](../docs/validation/README.md)。

## 边界

本版本面向桌面键盘游玩，未实现联网、账号、手机触控或手柄。静态页面需要通过 HTTP 服务访问，不能直接双击 `index.html`。浏览器清除站点数据后会清除本机纪录。

角色、车辆、赛道模型和音乐均由本项目生成。第三方库保留各自许可证；没有使用《猛兽派对》或参考图片中的游戏素材。
