# 萌爪海湾 · Pawprint Paradise

一款默认自动驾驶的原创海岛卡丁车游戏：四位动物车手、一条海岛赛道、三圈竞速。车辆自动加速和过弯，玩家把精力放在选线、氮气、道具和赛道互动上。TypeScript + Three.js，游戏逻辑、画面、音频与个人纪录全部在浏览器内运行。

## 开始游玩

远端构建版地址：[开始游玩](http://10.10.10.1:4173/)。

使用启用硬件加速、支持 WebGL 2 的桌面浏览器。电脑需要能访问 `10.10.10.1` 所在局域网。首次点击菜单后才会启用声音。

### 轻松驾驶（默认）

不用一直按油门，也不用精确控制方向。完全不操作也能跑完三圈；主动选择补给路线、冲刺和把握互动时机会更快。画面底部与提示卡上的按钮均可点击。

| 按键                  | 操作                           |
| --------------------- | ------------------------------ |
| A / ←                 | 选择左线，自动保持             |
| W / ↑（S / ↓ 也可以） | 回到中线                       |
| D / →                 | 选择右线，自动保持             |
| 空格                  | 氮气冲刺，按一次消耗 30 点     |
| E                     | 使用道具                       |
| F                     | 在提示窗口完成飞跃、漂移或回旋 |
| R                     | 返回最近有效检查点             |
| Esc                   | 暂停 / 继续                    |

- 氮气初始 60 点、上限 100 点，持续恢复；拾取青色晶体额外补充 20 点。冲刺持续约 1.8 秒，结束后再按一次可继续点火。
- 每圈两处选线门：左线补充 35 点氮气，右线给道具（已有道具时补充 20 点氮气），中线安全通过并补充 10 点氮气。计时模式右线提供短时加速。
- 每圈三次互动：木桥飞跃、砂岩漂移、海风回旋。按 F 抓住金色窗口，可获得更多氮气与加速；错过不会撞停。跳跃与回旋期间仍自动跟线。
- 受击仍会减速，但车辆自行恢复。恢复期间氮气与互动按钮会明确禁用，道具仍可由玩家决定使用。

### 手动驾驶（选角页切换）

原来的驾驶方式完整保留。手动与轻松驾驶的个人纪录分开，旧版本成绩不会被新模式覆盖。

| 按键        | 操作                                 |
| ----------- | ------------------------------------ |
| W / ↑       | 加速                                 |
| S / ↓       | 刹车；低速时倒车                     |
| A、D / ←、→ | 左右转向                             |
| 空格 + 转向 | 漂移蓄力                             |
| 松开空格    | 释放漂移加速；蓝色为一级，金色为二级 |
| E           | 使用当前道具                         |
| R           | 回到最近通过的检查点                 |
| Esc         | 暂停 / 继续                          |

离开窗口或切换标签页会自动暂停。恢复比赛前清空旧按键，避免车辆突然转向或误用道具。

## 游戏内容

- **团团 / 小熊猫**：均衡；**薯条 / 水豚**：极速略高；**柚子 / 狐狸**：转向灵活；**冰棒 / 企鹅**：起步更快。
- **道具竞速**：玩家和 7 名 AI 比赛，轻松 / 标准 / 挑战三档难度，3 圈决胜。轻松档适合熟悉路线；标准与挑战档的对手会更积极地通过弯道，需要选线、氮气和互动来争取名次。
- **计时挑战**：独享赛道，没有对手和道具；计时纪录与道具赛分开。
- **晴浪海湾**：海滩、棕榈树林、木桥、村落和北岸砂岩弯道。青色地面箭头为加速带。
- **道具**：加速果汁（短时冲刺）、泡泡护盾（挡一次攻击，持续 6 秒）、前向水球、后置香蕉皮。
- 玩家完赛立即结算；尚未完赛的对手按有效赛道进度排列，并明确标记。
- 个人纪录按驾驶方式、角色和比赛模式保存。设置和纪录仅存在当前浏览器，不上传服务器。
- 音量、音乐开关与三档画质可在设置中调整；流畅档关闭动态阴影并降低渲染分辨率。

## 开发与构建

所有命令在远端仓库的 `game/` 内执行。已使用现有 Node 24.17.0 和 npm 11.13.0，没有安装或升级系统运行时。

远端非交互 SSH 默认 PATH 未包含 Node，可先执行：

```sh
export PATH=/opt/homebrew/opt/node@24/bin:$PATH
cd /Users/yangshuyun/workspace/dev/gpt-space-20260922-2/game
npm ci
npm run dev -- --host 10.10.10.1 --port 5173 --strictPort
```

访问开发版时使用 **http://10.10.10.1:5173/**。远端回环地址的相同端口可能属于其他服务，因此验证使用明确的局域网地址。

```sh
npm test
npm run build
npm run preview
```

`npm run build` 先进行 TypeScript 检查，再生成 `dist/`。该目录可由普通静态 HTTP 服务承载；资源已打包，运行时不依赖 CDN、在线字体或外部素材服务。Vite 的单包大小提示来自随包交付的三维引擎，实际传输大小见验证报告。

初版依赖已固定版本，并提交 `package-lock.json`；本次驾驶改版没有新增或升级依赖：

- 运行依赖：Three.js。
- 开发与验证：TypeScript、Vite、Three.js 类型、Vitest、Playwright Core、Prettier。
- Playwright 使用远端已有的 Google Chrome，不下载浏览器。

## 源码结构

- `src/simulation.ts`：自动跟线 / 手动驾驶、氮气、选线奖励、时机动作、AI、比赛规则与道具。
- `src/track.ts`：赛道曲线、等距采样、道路投影和高度。
- `src/models.ts`、`src/world.ts`：原创动物、车辆、海岛、灯光、镜头、特效及资源释放。
- `src/ui.ts`、`src/style.css`：菜单、选角、HUD、暂停、设置和成绩。
- `src/input.ts`、`src/audio.ts`、`src/storage.ts`：键盘输入、合成音效与音乐、设备内存档。
- `src/types.ts`：模块共享类型。
- `test/`：规则、输入、12 种角色 / 难度的零操作完赛、奖励、纪录兼容及完整 AI 比赛测试。
- `scripts/assisted-qa.mjs`：新玩法完整流程、真实时间零操作 / 主动操作对照、提示边界与存档检查。
- `scripts/production-qa.mjs`：构建版自动加速、选线、氮气、暂停、资源离线性和禁止存储访问检查。
- `scripts/repair-qa.mjs`：选项切换后的键盘焦点、320 / 575 / 700 像素窗口中的成绩信息与横向溢出，以及异常成绩存档的结算、保存和刷新恢复。
- `scripts/browser-qa.mjs`：菜单、真实键盘漂移、道具、暂停、重开、成绩、纪录和布局检查。
- `scripts/keyboard-race-qa.mjs`：真实时间、实际键盘控制的三档难度完整比赛及帧时记录。

模拟使用 60Hz 固定步长，绘制使用插值。轻松驾驶沿赛道等距采样推进，平滑调整车道偏移；手动模式保留自由转向物理。两种模式共享检查点、碰撞、道具、排名和比赛流程。开发版的 `__PAWPRINT_TEST__` 测试入口会在生产构建时移除。

## 验证脚本

运行浏览器检查前，在仓库根目录创建本任务专属临时目录并放置 `.codex-tmp` 标记，将绝对路径通过环境变量传入。所有测试截图、日志和浏览器临时文件应留在该目录。

```sh
QA_ARTIFACT_DIR=/absolute/path/to/marked-task-directory \
TMPDIR=/absolute/path/to/marked-task-directory \
npm run qa
```

同样设置环境变量后，`npm run qa:assisted` 运行约 5 分钟的新玩法浏览器检查，`node scripts/keyboard-race-qa.mjs` 运行手动版长时间键盘测试。两者使用开发版测试入口；`npm run qa:production` 测试 4173 构建版。可用 `QA_BASE_URL` 指定新玩法 / 构建版的实际地址（例如端口回退到 4174 时）。

同样设置 `QA_ARTIFACT_DIR` 和 `TMPDIR` 后，`npm run qa:repair` 可快速检查本轮界面修复。两变量须指向同一个带 `.codex-tmp` 标记的本任务目录，避免截图与浏览器临时文件写入其他位置。

源码格式可用 `npm run format:check` 检查；`npm run format` 仅整理本游戏内的文件。

详细结果见 `VALIDATION.md`。

## 边界

本版本面向桌面键盘游玩，未实现联网、账号、手机触控或手柄。静态页面需要通过 HTTP 服务访问，不能直接双击 `index.html`。浏览器清除站点数据后会清除本机纪录。

角色、车辆、赛道模型和音乐均由本项目生成。第三方库保留各自许可证；没有使用《猛兽派对》或参考图片中的游戏素材。
